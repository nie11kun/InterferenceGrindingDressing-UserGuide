8. 零件库与系统设置

通过顶部菜单栏 工具 -> 零件库 与 设置 / 关于，可实现三文件自包含工艺档案管理、中英文实时切换与多机配置同步。

本章内容

  • 8.1 零件库管理
    • 五列表格结构、双向点击排序与一键回填；
    • igd_config_main.json、igd_config_draw.json、igd_config_tool.json 三文件完整快照机制。
  • 8.2 菜单与配置迁移
    • 顶部 设置（语言 / 检查更新 / 更新日志）、工具、关于 菜单说明；
    • ~/.igd/ 配置目录结构与跨工控机零误差下发方案。
