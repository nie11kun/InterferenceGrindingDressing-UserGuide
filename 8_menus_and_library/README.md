# 第 8 章 零件库管理与系统设置

在多品种、小批量的精密丝杠、转子与蜗杆生产车间中，一名工艺员往往需要维护数十乃至上百种不同规格型号工件的修整参数。**IGD** 通过顶部菜单栏 **`工具 -> 零件库`** 提供了企业级**“参数 + 源齿形 DXF + 伴随说明”三位一体归档管理系统**，彻底告别手工翻找历史文件夹与重复输入参数的繁琐操作。

---

   详解 **`工具 -> 零件库`** 窗口的五列表格视图、点击表头双向排序、三文件自包含归档结构（`settings.json` + `<零件名>.dxf` + `<零件名>-info.txt`），以及 **`新增`**、**`修改`**、**`刷新`**、**`删除`** 与一键 **`导入`** 的完整操作规范。
