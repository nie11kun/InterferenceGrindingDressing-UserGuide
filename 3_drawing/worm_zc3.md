# 蜗杆-ZC3 (轴向圆弧)

用于生成 ZC3 型（轴向圆弧）蜗杆的齿形。

## 1. 输入模式与直径参数

* **说明**: 同 ZC1 型。

## 2. 轴向模数 / 头数

* **说明**: 同 ZC1 型。

## 3. 圆弧半径

* **说明**: 轴向齿面的圆弧半径，单位为 mm。

## 4. 轴向压力角

* **说明**: 轴向齿面的压力角，单位为 °。
* **修正**: 支持对左/右侧轴向压力角进行修正。

## 5. 变位系数 / 齿厚系数

* **变位系数**: 支持对变位系数进行微调。
* **齿厚系数**: 
    * **标准值**: $0.5$。表示齿厚和齿槽宽比例为1:1。
    * **修正**: 支持对齿厚系数进行微调。

## 6. 齿高模式与参数

* **说明**: 同 ZC1 型。

## 7. 修整延长 / 齿顶圆弧半径

* **说明**: 同 ZC1 型。

## 8. 保存文件

* **说明**: 同 ZC1 型。
