下面介绍如何使用"XY 点位文件"功能，帮助您快速生成所需的 DXF 文件。

1. 参数说明

1.1 点位文件地址

  • 作用：指定包含 XY 点位数据的文本文件路径。
  • 设置建议：点击右侧"选择文件"按钮，选择本地的点位数据文件（如 shape.txt）。

1.2 选择类型

  • 作用：选择导入数据是单个文件还是整个文件夹。
  • 说明：如果选择文件夹，软件将批量处理该文件夹下的所有点位文件。

1.3 XY 数据索引号

  • 作用：指定每一行数据中，哪两列分别代表 X 和 Y 坐标。
  • 设置建议：输入两位数字（如 01），表示第 0 列为 X，第 1 列为 Y。

1.4 交换 XY 数据

  • 作用：是否将 X、Y 坐标数据互换。
  • 设置建议：如果选择“是”，则第一个索引对应 Y，第二个索引对应 X。

1.5 比例系数

  • 作用：对 X、Y 坐标进行缩放或镜像。
  • 设置建议：输入 X 和 Y 的比例值。输入 -1 可实现对应轴的镜像。

1.6 保存文件

  • 作用：指定生成的 DXF 文件保存路径。
  • 设置建议：点击右侧"选择文件"按钮，选择或输入保存的文件路径（如 output.dxf）。

2. 注意事项

  • 点位文件需为标准文本格式，内容应包含有效的 XY 坐标数据。
  • 索引号应为正整数，确保数据读取正确。
  • 若生成失败，请检查文件路径、数据格式及参数设置建议是否正确。

如有更多问题，请参考软件帮助文档或联系技术支持。
