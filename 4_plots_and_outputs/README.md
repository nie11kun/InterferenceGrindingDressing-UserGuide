# 第 4 章 可视化交互画布与输出文件解析

当您在 `基本参数` 或 `高级参数` 中点击左下角的 **`生成代码`** 按钮后，IGD 不仅会在 `输出程序路径` 下生成可直接上机运行的数控修整宏程序与伴随 DXF 文件，还会在右侧交互式绘图画布底部激活 **6 大核心计算结果视图**，供工程师从原始齿形导入、多直径阶梯演变、圆弧拟合残差、空间干涉修正量到最终 CNC 走刀轨迹进行全链路可视化复核。
