# 4.2 输出文件体系详解（DXF、宏程序与 HTML 报表）

IGD 在不同功能模块下会生成结构化的工程文件，涵盖**数控修整宏程序**、**标准 CAD 交换图档（`.dxf`）**、**参数伴随文件（`*-info.txt`）**、**误差统计文本（`.txt`）**以及**三维交互式可视化网页报表（`.html`）**。

---

## 二、三大主流数控系统宏程序代码结构剖析

### 1. 西门子（Siemens 840D sl / ONE）—— 以 `模式-0`（`.SPF`）为例

```gcode
; ==========================================
; Work Type: Internal | Handness: Right
; Pitch Diameter: 20.0 | Lead: 20.0
; Wheel Angle: 15.0 | Dresser Radius R/L: 0.2 / 0.2
; ==========================================
IF DRESSER[40]==1 GOTOF READ_PARA
; --- 砂轮直径阶梯分支跳转 ---
IF (DRESSER[24]<=17.0) AND (DRESSER[24]>16.9) GOTOF STEP_0
IF (DRESSER[24]<=16.9) AND (DRESSER[24]>16.8) GOTOF STEP_1
...
STOPRE
MSG("Wheel Diameter Out Of Range!")
M0
GOTOF END_PROG

STEP_0:
IF DRESSER[44]==1 GOTOF STEP_0_LEFT
; --- 右侧修整轨迹 (Right Dress) ---
G1 W=1.8452 U=-0.5210
G3 W=1.6210 U=-0.4125 I=-0.1520 J=0.1284
G2 W=0.0000 U=-0.0002 I=-0.8105 J=-1.4820
GOTOF END_PROG

STEP_0_LEFT:
; --- 左侧修整轨迹 (Left Dress) ---
G1 W=-1.8452 U=-0.5210
G2 W=-1.6210 U=-0.4125 I=0.1520 J=0.1284
...
END_PROG:
M17
```

* **核心运行逻辑**：
  1. 当机床主程序置 `DRESSER[40]=1` 调用该子程序时，子程序直接跳转至底部的 `READ_PARA` 段，向机床写入本次允许的最大/最小砂轮直径与左右滚轮半径后立即返回；
  2. 正常修整调用（`DRESSER[40]=0`）时，子程序读取当前砂轮实时直径 `DRESSER[24]`，自动匹配进入对应的 `STEP_k` 档位；
  3. 再根据 `DRESSER[44]`（`0` = 修右侧，`1` = 修左侧）执行对应侧的高精度 `G1`/`G2`/`G3` 走刀，修完即跳转至 `END_PROG` 结束（`M17`）。

### 2. 发那科（Fanuc 0i / 31i）—— 以 `模式-5`（`O2010`）为例

* 采用发那科标准宏变量语法（`#550=#603` 获取实时砂轮直径），通过 `IF[#550 GE ...] GOTO ...` 跳转至对应行号 `N...`，使用 `Z`（水平轴）与 `X`（进刀轴）及 `I`/`K` 圆心增量执行插补，以 `M99` 返回主程序。

### 3. 新代（Syntec）—— 以 `模式-6`（`O2010.txt`）为例

* 文件首行声明 `%@MACRO`，注释采用双斜杠 `//`，变量赋值采用 `:=`（如 `#350 := #340;`），条件分支采用 `IF (#350 <= ...) AND (#350 > ...) THEN GOTO ... END_IF;`，完全契合新代系统高级宏语言规范。
