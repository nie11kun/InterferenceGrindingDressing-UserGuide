软件简介

IGD 用户操作指南

欢迎使用 干涉磨削砂轮修整软件（IGD，Interference Grinding & Dressing v3.23.0） 官方用户操作手册！

适用对象与支持工件

  • 面向人群：数控螺纹磨床操作工、磨削工艺工程师、刀具设计工程师与现场调试人员。
  • 涵盖齿形：
    • 内/外螺纹：滚珠丝杠螺母（哥特式双圆弧）、行星滚柱丝杠（三角）、梯形与锯齿形螺纹；
    • 非对称型线：双螺杆压缩机阴阳转子、渐开线齿轮与花键；
    • 精密蜗杆：ZI、ZA、ZN1、ZC1、ZC2、ZC3、ZK1 共 7 种标准圆柱蜗杆。
  • 核心目标：消除空间啮合曲率干涉与孔口过切，一键生成多砂轮直径数控修整宏程序与高精度 DXF。

核心功能速览

  • 三维空间螺旋面包络与侧边修正
    • 基于微分几何啮合方程，消除大导程螺纹与非对称型线磨削干涉。
    • 支持 内螺纹 与 外螺纹（含 普通砂轮 外啮合与 内旋风铣 内包络两种构型）。
    • 提供 侧边修正 算法（保持现状 / 均衡过切和残留 / 绝对禁止过切），通过二分搜索自动优化肩部截断与延长角度。
  • 滚轮半径补偿与平滑圆弧拟合
    • 支持左右 滚轮圆弧半径 独立偏置，内置 齿根倒圆半径 防过切安全下限钳制。
    • 双切圆弧自适应拟合（拟合误差 单位 0.1 μm，单段圆弧扫角 ≤ 150°，输出首尾平滑连续的 G2/G3 轨迹）。
    • 自动统计去重后的实际最大/平均误差，并写入输出 DXF、HTML 与 TXT 报表。
  • 常驻进程池加速与 14 种数控程序模式
    • 授权通过后在后台自动预热常驻多核计算进程池与 Numba 缓存，多直径计算耗时降至约 8 秒。
    • 支持 砂轮杆偏移 与 砂轮直径 双输入模式及阶梯补偿子程序生成。
    • 预设 14 种 程序模式，覆盖 Siemens（.SPF / .CPF）、Fanuc（O2010）、Syntec 新代（O2010.txt） 与纯 DXF 模式（模式-10 / 模式-99）。
  • 五大标准齿形建模与六大工程分析工具箱
    • 绘图工具：免 CAD 参数化生成 螺纹（三角/梯形/双圆弧）、XY 点位文件、齿轮（渐开线齿轮/花键）与 7 种 蜗杆 DXF。
    • 工具箱：集成 最大偏移（3D 防撞）、滚道曲线计算（公差敏感度仿真）、DXF 处理（5 合 1 批处理，含 X/Y 独立缩放）、曲线转换、曲线误差对比 与 车刀计算（输出线切割 DXF 与 -3D.html）。
  • 三文件自包含零件库
    • 完整归档主参数、绘图参数与工具箱参数（igd_config_*.json），支持五列表格排序检索与一键回填。

系统需求与技术支持

  • 硬件运行环境：
    • 处理器 (CPU)：Intel Core i5 / AMD Ryzen 5 及以上（推荐 4 核以上主频处理器，多线程加速空间点云迭代计算）。
    • 内存 (RAM)：建议 8 GB 及以上（处理密集型转子与多档阶梯修整时推荐 16 GB）。
    • 显示器：1920 × 1080 或 2560 × 1440，支持 Windows / macOS 高分屏 DPI 缩放。
    • 接口设备：标准 USB 2.0 / 3.0 接口（使用硬件加密狗授权时）。
  • 操作系统支持：
    • Windows 10 (64-bit) / Windows 11 (64-bit)。
    • macOS 12+（支持触控板双指捏合与双指滚动缩放；Siemens程序加密 模块为 Windows 专用）。
