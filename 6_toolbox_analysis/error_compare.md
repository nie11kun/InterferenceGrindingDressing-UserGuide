# 6.4 曲线误差对比

**`工具箱 -> 曲线误差对比`** 用于定量比对两条 DXF 曲线间的微米级法向偏差，适用于理论齿形与实测样件、拟合曲线与原始样条或不同工艺参数轮廓之间的差异评估。

---

## 参数说明

| 参数名称 | 默认值 / 选项 | 工程含义与设置要点 |
| :--- | :--- | :--- |
| **`曲线 1 (基准)`** | `.dxf` 文件 | 作为对比基准的理论或参考曲线 |
| **`曲线 2 (对比)`** | `.dxf` 文件 | 待评估的实际或拟合曲线（如 `dxf_sumulator_normal_*.dxf`） |
| **`最大误差距离`** | `0.1`（mm） | 超出该距离阈值的首尾非重叠段视作超限区过滤，防止非工作段干扰有效齿面极值统计 |
| **`曲线方向`** | `X轴` / `Y轴` | 沿齿槽水平展开选 `X轴`；沿垂直轴上下展开选 `Y轴` |
| **`保存文件`** | `.dxf` 路径 | 自动在同目录输出 `-differences.dxf` 及 `-differences.html`、`-curve-compare.html` |

---

## 视图分析与输出文件

1. 选中两条曲线与保存路径后点击 **`生成误差对比数据`**；
2. **画布视图**：
   * 主视图叠加显示基准曲线、对比曲线与超限区段；
   * 点击右下角 **`误差曲线`** 切换沿主轴展开的误差曲线与极值标注。
3. **输出文件明细**：
   * **`<文件名>-differences.dxf`**：写入误差分布曲线，并在图形内嵌文本中标注最大/最小误差、均值 ± 标准差、RMS 与有效点成功率；
   * **`<文件名>-differences.html` & `<文件名>-curve-compare.html`**：浏览器交互式放大检验单点误差。
