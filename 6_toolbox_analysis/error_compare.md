# 6.4 曲线误差对比：理论齿形与实测/拟合曲线偏差分析

在工艺验证、逆向工程与质量检验中，经常需要定量比对两条DXF曲线之间的微米级差异，例如：
* 对比**三坐标/轮廓仪实测齿形 DXF** 与 **理论设计齿形 DXF**，评定试磨样件的齿形公差；
* 对比**圆弧拟合后的 DXF** 与 **原始高密度样条 DXF**，核验双圆弧逼近精度；
* 对比**不同砂轮安装角或不同砂轮直径**下生成的两条砂轮廓形 DXF，量化磨损前后的廓形变化量。

**`工具箱 -> 曲线误差对比`** 模块提供亚微米级法向偏差计算、可视化误差放大矢量图（DXF）以及完整误差统计报表（TXT）。

---

## 一、参数详解与配置指南

切换至 **`工具箱 -> 曲线误差对比`**，面板包含以下 5 项输入参数：

| 参数名称 | 默认值 / 选项 | 工程含义与配置说明 |
| :--- | :--- | :--- |
| **`曲线 1 (基准)`** | 选择 `.dxf` 文件 | 导入作为评价基准的参考曲线（如理论标准齿形 DXF）。 |
| **`曲线 2 (对比)`** | 选择 `.dxf` 文件 | 导入待评定的对比曲线（如实测齿形、拟合后齿形或反演滚道 DXF）。 |
| **`最大误差距离`** | `0.1`（单位：$\text{mm}$） | **异常野点过滤阈值**：当两条曲线首尾长度不一致（例如其中一条带有水平延长段而另一条没有）时，凡是法向间距超过该阈值的首尾非重叠段将被自动剔除，不计入有效齿面误差统计，防止非工作段拉偏最大误差值。 |
| **`曲线方向`** | `X轴` / `Y轴` | 指定曲线展开的主方向：<br>• **`X轴`**（默认）：适合绝大多数沿水平 $X$ 轴左右展开的螺纹、蜗杆、齿轮齿槽曲线；<br>• **`Y轴`**：适合沿垂直 $Y$ 轴上下展开的立式廓形曲线。 |
| **`保存文件`** | 选择输出 `.dxf` 路径 | 指定结果保存路径。系统将同时生成 `<文件名>.dxf`（带放大误差矢量的可视化对比图）与 `<文件名>.txt`（误差统计报表）。 |

---

## 二、执行对比、查看 `误差曲线` 与判读统计报表

1. 依次选择 **`曲线 1 (基准)`**、**`曲线 2 (对比)`** 与 **`保存文件`** 路径，点击左下角主按钮 **`生成误差对比数据`**；
2. **主画布与专属 `误差曲线` 视图切换**：
   * 计算完成后，右侧主画布显示基准曲线（蓝色）与对比曲线（红色）的叠加图；
   * 点击右下角自动浮现的紫色 **`误差曲线`** 按钮，画布切换为沿主方向展开的**法向误差分布曲线（单位：$\mu\text{m}$）**，并标注正向最大偏差与负向最大偏差极值点。
3. **输出文件解析**：
   * **`<文件名>.txt` 统计报表**：记录全齿面采样点的**最大正误差（Max Positive Error）**、**最大负误差（Max Negative Error）**、**平均绝对误差（Mean Error）**、**均方根误差（RMS Error）**以及逐点坐标与法向偏差明细表；
   * **`<文件名>.dxf` 误差矢量图**：在 AutoCAD 中打开该文件，不仅能看到两条原始曲线，还能看到沿法向按比例放大的误差梳状矢量线（Error Comb），非常适合插入产品质量检测报告。
