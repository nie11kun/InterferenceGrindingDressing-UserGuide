10. 报警排查与 FAQ

本章汇总了 干涉磨削砂轮修整软件（IGD） 的弹窗报警速查字典与现场调试高频 FAQ。

现场高频 FAQ

Q1：齿根倒圆半径被自动放大？

  • 原因：当 滚轮圆弧半径 为 0.2 mm 时，物理滚轮无法修出小于自身刀尖半径的内凹倒圆，否则会啃伤工作齿面；软件自动钳制 实际倒圆 = max(输入值, 滚轮半径)；
  • 解决措施：如需更小齿底圆角，需更换更小刀尖半径的金刚石滚轮。

Q2：牙型半角试磨偏差如何微调？

  • 原因：直接修改白底图纸基准值容易混淆设计尺寸与补偿量；
  • 解决措施：切勿改动白底基准框；在 绘图工具 对应参数右侧的 #6bb1aa 青绿色微调框输入 +0.04 或 -0.04，重生成 DXF 后再回 基本参数 生成代码。

Q3：圆弧方向相反或终点报警？

  • 原因：CNC 修整轴正负极性或平面圆弧顺逆定义与模板默认不一致；
  • 解决措施：
    • 检查 程序信息 -> 进刀方向（负向 vs 正向）；
    • 在 初始化配置 中切换 G3 ⇆ G2 复选框并重新生成代码。

Q4：外部导入 DXF 报错如何清洗？

  • 原因：源图 Y = 0 未对齐中径，或含有 SPLINE、断开碎线；
  • 解决措施：先经 工具箱 -> DXF 处理 -> DXF 变换 平移校准 Y = 0 与 X = 0，再用 DXF 离散化（或 DXF 拟合圆弧）设为 自动识别 重构单条连续轮廓。

Q5：内螺纹孔口过切如何消除？

  • 原因：大导程干涉工况下砂轮肩部旋转扫掠切入工件孔口边缘；
  • 解决措施：进入 高级参数 -> 初始化配置，将 侧边修正 设为 均衡过切和残留（或严苛 绝对禁止过切），系统会自动搜寻最优肩部截断与延长角度并抑制孔口过切。

Q6：纯 DXF 模式无 .SPF？

  • 原因：模式-10 与 模式-99 为单砂轮直径纯 DXF 导出模式，专用于 CAD 检图或 CAM 编程；
  • 解决措施：如需生成包含全寿命直径分档的 .SPF / O2010 宏程序，请将 程序模式 切回对应数控模板（如 模式-0、模式-5 或 模式-100）。
