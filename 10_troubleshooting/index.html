第 10 章 常见报警排查与工程 FAQ

本章汇总了 IGD 磨削修整计算软件 在参数校验、空间螺旋面啮合求解、数控宏程序生成及现场试磨调试过程中可能出现的弹窗报警信息速查字典与高频工程问题 FAQ。

一、软件弹窗报警信息速查与排障字典

当输入参数存在物理矛盾或几何超限时，软件会拦截计算并弹出明确的错误提示。请对照下表快速定位并修正：

弹窗报警/提示原文 触发模块与原因分析 标准解决措施
存在未填或格式错误的参数！ 当前激活面板中存在空白输入框、非数字字符（如误输入中文句号 。 或空格），或必填文件/路径未选择。 检查当前标签页及子标签页所有输入框，确保数值为合法半角浮点数或整数，且已通过 选择文件/选择路径 指定了有效路径。
砂轮安装角过小，齿面存在过度过切风险，请重新设置参数！ 在 基本参数 或 滚道曲线计算 中，设定的 砂轮安装角 与工件理论螺旋升角相差过大，且砂轮直径较大，导致空间包络接触线发生二次自交（过切）。 1. 在不撞杆的前提下（用 工具箱 -> 最大偏移 校核），尽可能增大 砂轮安装角 使其接近理论螺旋升角；

2. 或适当减小 最大砂轮直径（增大 最小距离）。
最大砂轮直径必须大于最小砂轮直径！

或 最大距离必须大于最小距离！		 在 基本参数 中，上下限填反了（注意：偏移距离越大，对应的砂轮直径越小）。 • 当 输入方式 = 砂轮直径 时，确保 最大砂轮直径 > 最小砂轮直径；

• 当 输入方式 = 砂轮杆偏移 时，确保 砂轮杆偏移工件中心最大距离 > 砂轮杆偏移工件中心最小距离。
砂轮宽度过小，无法进行水平延长！ 在 高级参数 -> 初始化配置 中开启了 水平延长 = 是，但输入的 砂轮宽度 小于或等于齿形加上左右 齿根倒圆半径 后的总开口跨度。 增大 砂轮宽度 数值（使其大于齿槽开口宽 +++ 2×2 \times2× 齿根倒圆半径 +++ 至少 1 mm1\text{ mm}1 mm 平面余量），或将 水平延长 改为 否。
直径信息错误，工件大径需大于工件中径，工件小径需小于工件中径！ 在 绘图工具 -> 螺纹（三角/梯形/双圆弧）中，大径、中径、小径的大小顺序颠倒。 严格确保：工件小径 < 工件中径 < 工件大径。特别注意在 双圆弧 中切换内/外螺纹时，第 2 个直径框会自动在 工件大径 与 工件小径 之间切换！
齿根圆弧半径过大，无法生成齿形！

或 倒圆半径过大，无法完成倒圆！		 在 绘图工具 或 初始化配置 中，设定的 齿顶倒圆半径 或 齿根倒圆半径 超过了齿顶平段宽度或齿底剩余空间，导致两侧圆弧无法内切。 减小对应的 齿顶倒圆半径 或 齿根倒圆半径。
安装角设置过大 在 工具箱 -> 最大偏移 中，砂轮杆在给定孔长与小径下，即使偏移量为 0 也已经与螺母两端孔口碰壁。 减小 砂轮杆安装角，或更换更细的 砂轮杆直径。
原始曲线类型与目标曲线类型不能相同！ 在 工具箱 -> 曲线转换 中，原始曲线类型 与 目标曲线类型 选择了同一个截面名称。 将 目标曲线类型 修改为不同于原始类型的截面（如从 端面(左) 转为 法向）。
检测到未安装加密狗或加密狗无效！

或 加密狗连接断开，程序即将关闭！		 USB 硬件加密狗松动、接触不良，或插在了供电不足的前置 USB 集线器上。 将硬件加密狗直接插入工控机主板后置原生 USB 接口，重新点击 验证加密狗 或重启软件。
授权已过期，请联系管理员更新授权！ 当前加密狗或本地 .lic 授权文件已超过合同约定的授权截止日期。 联系官方技术支持获取最新 .lic 授权文件，在登录窗口底部点击 导入授权文件 即可立即续期。

二、高频工程应用 FAQ（现场调机必读）

Q1：为什么我在 高级参数 -> 初始化配置 中把 齿根倒圆半径 设为了 0.05 mm，但生成的砂轮廓形齿根圆角看起来还是 0.2 mm？

  • 解答：这是软件内置的金刚石滚轮防过切自动安全钳制机制。当您的 滚轮圆弧半径 设为 0.2 mm 时，物理上半径为 0.2 mm0.2\text{ mm}0.2 mm 的金刚石滚轮绝对不可能修出比它自身半径更小的 0.05 mm0.05\text{ mm}0.05 mm 内凹齿根圆角（强行走刀会导致滚轮侧刃啃伤砂轮工作齿面）。因此，只要开启了 水平延长 或 齿根倒圆半径 >0>0>0，软件会自动强制执行 实际齿根倒圆半径=max⁡(输入值,滚轮圆弧半径)\text{实际齿根倒圆半径} = \max(\text{输入值}, \text{滚轮圆弧半径})实际齿根倒圆半径=max(输入值,滚轮圆弧半径)。若确需更小的齿根圆角，必须更换刀尖半径更小的金刚石滚轮。

Q2：机床上试磨出来的双圆弧螺母或梯形丝杠，检测发现牙型半角偏小了 0.04∘0.04^\circ0.04∘，应该改哪里最稳妥？

  • 解答：切勿直接修改白底框中的标准图纸公称值！请回到 绘图工具 -> 螺纹，在对应的 右半角/左半角（或 双圆弧 的偏心/半径）右侧的 #6bb1aa 青绿色微调框 中输入补偿量（如 +0.04 或 -0.04），重新点击 生成齿形文件 ➔ 回到 基本参数 点击 生成代码。这样既完整保留了图纸原始公称值，又让工艺补偿量一目了然。

Q3：数控机床上运行生成的修整程序时，提示“圆弧终点不在圆上”或修出的砂轮凹凸方向反了，是什么原因？

  • 解答：这是由于机床数控系统的修整平面坐标系（G17/G18/G19）或前置/后置修整器方向与默认顺逆圆弧极性相反所致。请按以下两步排查：
    1. 检查 高级参数 -> 程序信息 中的 进刀方向（负向 vs 正向）是否与机床修整轴向砂轮中心切入时的坐标增减方向一致；
    2. 若进刀方向正确但圆弧凹凸相反，请切换至 高级参数 -> 初始化配置，勾选 拟合圆弧 右侧的 G3 ⇆ G2 复选框，重新点击 生成代码 即可解决。

Q4：外部导入的 CAD 齿形 DXF 在点击 生成代码 时报错或图形扭曲，如何快速修复？

  • 解答：外部 CAD 导出的 DXF 常见问题有两个：一是坐标原点在工件回转中心 (0,0)(0,0)(0,0) 而不在中径上；二是包含断开的碎线段或 SPLINE 样条。推荐标准修复流水线：
    1. 先用 工具箱 -> DXF 处理 -> DXF 变换，将分度圆/中径平移至 Y=0Y = 0Y=0，齿槽中心平移至 X=0X = 0X=0；
    2. 再用 工具箱 -> DXF 处理 -> DXF 离散化（或 DXF 拟合圆弧），将 曲线方向 设为 自动识别（或 升序 - X轴），一键将其重构为干净、有序、连续的标准 DXF 曲线。
