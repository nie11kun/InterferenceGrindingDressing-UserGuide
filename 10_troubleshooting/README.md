# 10. 报警排查与 FAQ

本章汇总了 **干涉磨削砂轮修整软件（IGD）** 的**弹窗报警速查字典**与现场调试高频 **FAQ**。

---

## 弹窗报警速查

| 报警信息原文 | 常见原因 | 解决措施 |
| :--- | :--- | :--- |
| **`请输入有效的数字`** / **`某个选项卡上的数据无效，请检查。`** | 存在空白输入框、非半角数字字符或格式不合法的输入项 | 检查当前及关联选项卡参数，改用半角有效数值并补全路径 |
| **`内螺纹情况下，最大和最小距离不能大于中径一半`** / **`外螺纹情况下，最大和最小距离不能小于中径一半`** | `砂轮杆偏移` 距离超出了工件中径半径的物理包络边界 | 核对 `工件中径` 与 `工件类型`，将偏移距离调整至合理侧 |
| **`砂轮杆偏移工件中心最大距离不能小于最小距离`** | 砂轮上下限填反（偏移越大对应砂轮直径越小） | 确保 `砂轮杆偏移` 满足 `最大距离 ≥ 最小距离`（`砂轮直径` 满足 `最大 ≥ 最小`） |
| **`安装角设置过大`** | `工具箱 -> 最大偏移` 计算中，零偏移下砂轮杆已与内孔两端碰撞 | 减小 `砂轮杆安装角`，或改用更小 `砂轮杆直径` 的接长杆 |
| **`延长线角度必须在 [0, 90) 范围内`** / **`截断量过大，剩余轮廓点不足`** | `延长线角度` 超出 `[0°, 90°)`，或极端干涉下侧边截断超出齿形跨度 | 将 `延长线角度` 设为 `0 ~ 89°`，或检查 `砂轮安装角` 与齿形深度是否合理 |
| **`右侧齿根圆角 ... 过大。`** / **`左侧齿根圆角 ... 过大。`** / **`半径 ... 太大 ... 超出了线段`** | 绘图工具或 DXF 倒圆中设定的圆角半径超出了相邻线段可用长度 | 适当减小 `齿顶倒圆半径`、`齿根倒圆半径` 或分段倒圆半径 |
| **`找不到文件: ... 请先导入齿形 DXF 文件。`** / **`请先执行'生成代码'或打开圆弧拟合功能`** | 源 DXF 路径失效/移动，或未开启 `拟合圆弧` 即点击 `圆弧拟合` 视图 | 重新点击 `选择文件` 指定存在的 DXF，或开启 `拟合圆弧 = 是` 后重新生成代码 |
| **`未找到加密狗硬件（请确认加密狗已正确插入 USB 接口）`** / **`加密狗已断开或会话已失效，无法执行核心计算！`** | USB 加密狗未插稳、运行途中松动或经过供电不足的扩展坞 | 插入工控机主板原生 USB 口，在登录页点击 `验证加密狗` 或重启软件 |
| **`授权许可已过期`** / **`授权设备不匹配`** / **`数字签名校验失败 (授权已被非法篡改)`** | `.lic` 许可超出有效期、拷贝自其他电脑硬件 ID 或文件损坏 | 联系官方获取匹配本机硬件 ID 的最新 `.lic` 文件，点击 **`导入授权文件`** 激活 |
| **`当前授权配置未开放该项功能，无法执行计算！请升级授权或插入对应加密狗。`** | 当前专机定制版授权未包含所选模块或程序模式 | 切回当前机床已授权的 `程序模式`，或联系技术支持升级全功能授权 |

## 现场高频 FAQ

### Q1：齿根倒圆半径被自动放大？

* **原因**：当 `滚轮圆弧半径` 为 `0.2 mm` 时，物理滚轮无法修出小于自身刀尖半径的内凹倒圆，否则会啃伤工作齿面；软件自动钳制 `实际倒圆 = max(输入值, 滚轮半径)`；
* **解决措施**：如需更小齿底圆角，需更换更小刀尖半径的金刚石滚轮。

### Q2：牙型半角试磨偏差如何微调？

* **原因**：直接修改白底图纸基准值容易混淆设计尺寸与补偿量；
* **解决措施**：切勿改动白底基准框；在 `绘图工具` 对应参数右侧的 **`#6bb1aa` 青绿色微调框**输入 `+0.04` 或 `-0.04`，重生成 DXF 后再回 `基本参数` 生成代码。

### Q3：圆弧方向相反或终点报警？

* **原因**：CNC 修整轴正负极性或平面圆弧顺逆定义与模板默认不一致；
* **解决措施**：
  * 检查 `程序信息 -> 进刀方向`（`负向` vs `正向`）；
  * 在 `初始化配置` 中切换 **`G3 ⇆ G2`** 复选框并重新生成代码。

### Q4：外部导入 DXF 报错如何清洗？

* **原因**：源图 `Y = 0` 未对齐中径，或含有 `SPLINE`、断开碎线；
* **解决措施**：先经 **`工具箱 -> DXF 处理 -> DXF 变换`** 平移校准 `Y = 0` 与 `X = 0`，再用 **`DXF 离散化`**（或 `DXF 拟合圆弧`）设为 `自动识别` 重构单条连续轮廓。

### Q5：内螺纹孔口过切如何消除？

* **原因**：大导程干涉工况下砂轮肩部旋转扫掠切入工件孔口边缘；
* **解决措施**：进入 **`高级参数 -> 初始化配置`**，将 **`侧边修正`** 设为 **`均衡过切和残留`**（或严苛 `绝对禁止过切`），系统会自动搜寻最优肩部截断与延长角度并抑制孔口过切。

### Q6：纯 DXF 模式无 `.SPF`？

* **原因**：`模式-10` 与 `模式-99` 为单砂轮直径纯 DXF 导出模式，专用于 CAD 检图或 CAM 编程；
* **解决措施**：如需生成包含全寿命直径分档的 `.SPF` / `O2010` 宏程序，请将 `程序模式` 切回对应数控模板（如 `模式-0`、`模式-5` 或 `模式-100`）。
