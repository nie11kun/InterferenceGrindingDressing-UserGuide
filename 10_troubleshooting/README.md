# 10. 报警排查与 FAQ

本章汇总了 **干涉磨削砂轮修整软件（IGD）** 的**弹窗报警速查字典**与现场调试高频 **FAQ**。

---

## 弹窗报警速查

| 报警信息原文 | 常见原因 | 解决措施 |
| :--- | :--- | :--- |
| **`存在未填或格式错误的参数！`** | 存在空白输入框、非半角数字字符或未指定必选文件/路径 | 检查当前面板数值与路径，改用半角浮点数并完成文件选择 |
| **`砂轮安装角过小，齿面存在过度过切风险，请重新设置参数！`** | `砂轮安装角` 与理论升角差值过大且砂轮直径较大，接触线发生二次自交 | 先用 `工具箱 -> 最大偏移` 校核后尽量增大 `砂轮安装角`，或减小 `最大砂轮直径` |
| **`最大砂轮直径必须大于最小砂轮直径！`** / **`最大距离必须大于最小距离！`** | 上下限填反（偏移越大对应砂轮直径越小） | `砂轮直径` 模式满足 `最大 > 最小`；`砂轮杆偏移` 模式满足 `最大距离 > 最小距离` |
| **`砂轮宽度过小，无法进行水平延长！`** | `水平延长 = 是` 时输入的 `砂轮宽度` 小于齿槽宽加两侧倒圆总跨度 | 增大 `砂轮宽度`（至少高于 `开口宽 + 2×倒圆半径 + 1 mm`），或关闭 `水平延长` |
| **`直径信息错误，工件大径需大于工件中径，工件小径需小于工件中径！`** | 大径、中径、小径大小顺序颠倒 | 严格保持 `工件小径 < 工件中径 < 工件大径` |
| **`齿根圆弧半径过大，无法生成齿形！`** / **`倒圆半径过大，无法完成倒圆！`** | 倒圆半径大于齿顶/齿底剩余可用几何空间 | 适当减小 `齿顶倒圆半径` 或 `齿根倒圆半径` |
| **`安装角设置过大`** | `最大偏移` 计算中，零偏移下砂轮杆已与内孔两端发生碰撞 | 减小 `砂轮杆安装角` 或改用更小 `砂轮杆直径` |
| **`原始曲线类型与目标曲线类型不能相同！`** | `曲线转换` 的输入与输出截面选成同一类型 | 修改 `目标曲线类型` 为不同截面（如 `端面(左)` ➔ `法向`） |
| **`检测到未安装加密狗或加密狗无效！`** / **`加密狗连接断开，程序即将关闭！`** | 硬件加密狗松动、未插稳或经过供电不足的前置扩展坞 | 插入主机主板原生 USB 口后点击 `验证加密狗` 或重启软件 |
| **`授权已过期，请联系管理员更新授权！`** | 加密狗或 `.lic` 文件超出授权截止日期 | 获取最新 `.lic` 文件，在登录窗口点击 **`导入授权文件`** 续期 |

## 现场高频 FAQ

### Q1：齿根倒圆半径被自动放大？

* **原因**：当 `滚轮圆弧半径` 为 `0.2 mm` 时，物理滚轮无法修出小于自身刀尖半径的内凹倒圆，否则会啃伤工作齿面；软件自动钳制 `实际倒圆 = max(输入值, 滚轮半径)`；
* **解决措施**：如需更小齿底圆角，需更换更小刀尖半径的金刚石滚轮。

### Q2：牙型半角试磨偏差如何微调？

* **原因**：直接修改白底图纸基准值容易混淆设计尺寸与补偿量；
* **解决措施**：切勿改动白底基准框；在 `绘图工具` 对应参数右侧的 **`#6bb1aa` 青绿色微调框**输入 `+0.04` 或 `-0.04`，重生成 DXF 后再回 `基本参数` 生成代码。

### Q3：圆弧方向相反或终点报警？

* **原因**：CNC 修整轴正负极性或平面圆弧顺逆定义与模板默认不一致；
* **解决措施**：
  * 检查 `程序信息 -> 进刀方向`（`负向` vs `正向`）；
  * 在 `初始化配置` 中切换 **`G3 ⇆ G2`** 复选框并重新生成代码。

### Q4：外部导入 DXF 报错如何清洗？

* **原因**：源图 `Y = 0` 未对齐中径，或含有 `SPLINE`、断开碎线；
* **解决措施**：先经 **`工具箱 -> DXF 处理 -> DXF 变换`** 平移校准 `Y = 0` 与 `X = 0`，再用 **`DXF 离散化`**（或 `DXF 拟合圆弧`）设为 `自动识别` 重构单条连续轮廓。

### Q5：内螺纹孔口过切如何消除？

* **原因**：大导程干涉工况下砂轮肩部旋转扫掠切入工件孔口边缘；
* **解决措施**：进入 **`高级参数 -> 初始化配置`**，将 **`侧边修正`** 设为 **`均衡过切和残留`**（或严苛 `绝对禁止过切`），系统会自动搜寻最优肩部截断与延长角度并抑制孔口过切。

### Q6：纯 DXF 模式无 `.SPF`？

* **原因**：`模式-10` 与 `模式-99` 为单砂轮直径纯 DXF 导出模式，专用于 CAD 检图或 CAM 编程；
* **解决措施**：如需生成包含全寿命直径分档的 `.SPF` / `O2010` 宏程序，请将 `程序模式` 切回对应数控模板（如 `模式-0`、`模式-5` 或 `模式-100`）。
