# 9.5 案例五：渐开线花键/非标 DXF 齿形处理与圆弧拟合（SPL-60T）

在日常加工中，常遇到客户直接发来总图上截取的样条 DXF（原点在工件中心而不是中径上，且为老旧数控系统无法直接运行的 `SPLINE` 图元）。本案例数据严格源自零件库实际工程档案（档案代号：`江阴得灵` / `厦大` 渐开线测试件，工业标准脱敏代号 **`SPL-60T`**），演示完整的 DXF 处理与圆弧拟合全流程。

---

## 一、真实工程参数一览表（型号：`SPL-60T`）

| 参数面板 | 核心参数名称 | 真实输入数值 | 工艺解析与现场设定 |
| :--- | :--- | :--- | :--- |
| **`绘图工具 -> 齿轮 -> 渐开线`** | `渐开线类型` | **`花键`** | 切换至渐开线花键专用模式。 |
| | `法向模数` ($m_n$) / `齿数` ($z$) | `3.25 mm` / **`60`** | 重载渐开线花键规格，分度圆直径 $d = 3.25 \times 60 = 195.0\text{ mm}$。 |
| | `法向压力角` | `23.5°` | 实际工件非标压力角。 |
| | `螺旋角` / `螺纹旋向` | `3.393°` / `右旋` | 小螺旋角斜花键。 |
| | `齿厚系数` | `0.5` | 标准齿厚。 |
| | `齿高调节` | $d_a=201.382\text{ mm}, d_f=190.882\text{ mm}$ | 真实齿顶与齿根圆直径。 |
| | `修整延长` / `齿顶倒圆` | `0.5 mm` / `0.2 mm` | 齿端延伸与过渡圆角。 |
| **`工具箱 -> DXF 处理`** | `DXF 变换` 平移距离 | `X: 0.0`, **`Y: -97.5 mm`** | 将分度圆半径从 $Y=+97.5\text{ mm}$ 移至 $Y=0$ 基准线。 |
| | `DXF 拟合圆弧` 拟合误差 | **`1.0 μm`** | 将 `SPLINE` 样条高精拟合为纯相切圆弧 DXF。 |
| | `DXF 离散化` 点密度 | `500` | 重新生成有序离散点云。 |
| **`工具箱 -> 曲线误差对比`** | `最大误差距离` | `0.05 mm` | 剔除端部非重叠异常点。 |
| | `曲线方向` | `X轴` | 沿横轴对比法向残差。 |

---

## 二、关键操作步骤

- **第 1 步：平移基准点至 $Y=0$**：
  - 打开 `工具箱 -> DXF 处理 -> DXF 变换`，载入客户原始花键 DXF。
  - 在平移距离 `Y:` 中输入 `-97.5`（即向下平移分度圆半径值），点击 `生成变换 DXF`，使中径严格对准 $Y=0$。
- **第 2 步：样条转相切圆弧拟合**：
  - 切换至 `工具箱 -> DXF 处理 -> DXF 拟合圆弧`，载入平移对齐后的 DXF。
  - 设定 `拟合误差` = `1.0 μm`，点击 `生成拟合数据`，直接导出全由 `G2`/`G3` 圆弧组成的合规 DXF。
- **第 3 步：曲线误差对比与验证**：
  - 切换至 `工具箱 -> 曲线误差对比`，将理论生成的 DXF 作为基准、拟合后的圆弧 DXF 作为对比。
  - 点击 `生成误差对比数据`，再点击紫色 **`误差曲线`** 按钮，直观核验全齿面残差全部在 $1\ \mu\text{m}$ 允许公差带以内！
