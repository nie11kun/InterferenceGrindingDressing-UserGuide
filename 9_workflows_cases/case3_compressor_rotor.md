# 9.3 案例三：螺杆压缩机阴阳转子外螺纹成形磨削（SRM-300F / 301M）

双螺杆压缩机阴阳转子是大导程、深齿槽、强非对称端面型线的外螺纹代表。本案例参数严格取自零件库实际工程档案（档案代号：`LGY-03HC-300 阴转子` 与 `LGY-03HC-301 阳转子`，工业标准脱敏代号 **`SRM-300F`** 与 **`SRM-301M`**）。

## 二、转子成形磨削三大核心法则

- **法则 1：齿形类型必须选 `端面(左)`**：
  - 转子设计软件（如 SRM 型线）导出的均是端面横截面，绝非垂直于螺旋槽的法向截面。若误选法向，计算出的砂轮槽宽将严重失真。
- **法则 2：必须开启 `轮廓x0法向匹配齿型x0` = `是`**：
  - 非对称转子齿底法向在三维空间中偏离对称轴，若不开启此开关，砂轮对刀零点会沿轴向横向漂移数毫米，导致无法对刀。
- **法则 3：大角度斜坡延长（`65°`）**：
  - 通过 `水平延长` = `是`、`延长线角度` = `65`，让金刚石滚轮顺带将砂轮两侧修出 $65^\circ$ 的避空斜面，避免端面擦伤工件外圆。
