二、螺杆转子成形磨削四大核心技术要点

1. 为什么 DXF 齿形类型 必须选 端面(左)？

压缩机转子的啮合型线（如 SRM、GHH 或自定义非对称型线）在流体热力学设计软件中均是在垂直于转子轴线的端面横截面（Transverse Section）上定义并导出 DXF（或通过 绘图工具 -> XY 点位文件 转成 DXF）的。因此导入 基本参数 时，必须将 DXF 齿形类型 设为 端面(左)，并配合 镜像 开关使转子吸气侧与排气侧方向与转子磨床头架/尾座装夹朝向一致。

2. 为什么必须开启 轮廓x0法向匹配齿型x0 = 是？

转子齿槽底部并非对称圆弧，在 X=0X = 0X=0 基准点处曲线往往带有一定斜率。若将 轮廓x0法向匹配齿型x0 留在默认的 否，三维螺旋面包络计算出的砂轮顶点会沿着法矢方向发生横向偏移，导致机床上无法以 X=0X = 0X=0 作为砂轮对刀中心。将其设为 是 后，软件强制将生成的砂轮廓形 X=0X=0X=0 锚定在转子齿形 X=0X=0X=0 的空间法向对应点上，保证对刀基准零漂移。

3. 高点密度（2000）与严苛拟合误差（0.5 μm）

转子单个齿槽弧长达 50∼90 mm50 \sim 90\text{ mm}50∼90 mm，且由 5~7 段不同曲率的圆弧、摆线与包络线拼接而成。将 最终曲线点密度 提升至 1000 ~ 2000，并将 拟合误差 收紧至 0.5 (μm\mu\text{m}μm)，可确保在各组成曲线交接点处不损失任何微米级型线特征。

4. 大宽度斜坡延伸（水平延长 = 是，延长线角度 = 65°）

在 SRM-300F 与 SRM-301M 所使用的专用转子磨床（对应 模式-1）上，金刚石滚轮直径较大（滚轮圆弧半径 = 1.5 mm），且需要将砂轮两侧边缘修出 65∘65^\circ65∘ 避空斜坡。通过开启 水平延长 = 是、设置 砂轮宽度 = 46（阴转子）/ 56（阳转子）、延长线角度 = 65，即可一次性生成包含工作型面与两侧护坡的完整修整刀路。
