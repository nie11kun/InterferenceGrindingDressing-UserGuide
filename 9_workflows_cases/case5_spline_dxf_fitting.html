9.5 渐开线花键与 DXF

9.5 渐开线花键与 DXF

本案例以脱敏标准型号 SPL-60T（60 齿重载渐开线花键） 为例，演示如何将外部 CAD 导出的高密度样条或圆心原点图档清洗对齐 Y = 0，完成平滑圆弧拟合与误差验证。

工艺参数配置表（SPL-60T）

参数面板 参数名称 设定值 说明
绘图工具 -> 齿轮 -> 渐开线 渐开线类型 花键 按 齿顶圆直径 与 齿根圆直径 控制
法向模数 / 齿数 3.25 mm / 60 分度圆直径 195.0 mm（半径 97.5 mm）
法向压力角 / 螺旋角 / 旋向 23.5° / 3.393° / 右旋 非标小螺旋角斜花键参数

DXF 离散化 最终曲线点密度 500 重采样有序均匀点云
工具箱 -> 曲线误差对比 最大误差距离 / 曲线方向 0.05 mm / X轴 过滤非重叠端区并检验拟合残差

核心操作步骤

  1. 坐标归零与尺度缩放（DXF 变换）：
    • 载入以花键圆心为原点的外部 CAD 齿槽 DXF；
    • 在 缩放比例 核对 X: / Y:（若热处理存在差异胀缩可单独微调某轴比例），在 平移距离 Y: 填 -97.5 将分度圆移至 Y = 0。
  2. 样条转纯圆弧（DXF 拟合圆弧）：
    • 载入变换后的 *_transform.dxf，设定 拟合误差 = 10（允差 1.0 μm），生成 *_arcs.dxf、*_arcs.html 与 *_arcs.txt；
    • 核查右侧画布多色相切段（单段扫角 ≤ 150°）。
  3. 闭环精度复核（曲线误差对比）：
    • 对比理论齿形与 *_arcs.dxf，点击紫色 误差曲线 按钮确认全工作齿面残差均在 ± 1.0 μm 以内。
