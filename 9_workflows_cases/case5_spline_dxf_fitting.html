9.5 案例五：渐开线花键/非标 DXF 齿形处理与圆弧拟合（SPL-60T）

9.5 案例五：渐开线花键/非标 DXF 齿形处理与圆弧拟合（SPL-60T）

在工程实践中，工艺员获取渐开线花键或非标直槽/螺旋槽齿形通常有两种来源：

  • 来源一（正向参数化建模）：图纸给出了花键模数、齿数、压力角、齿顶圆与齿根圆，直接在 绘图工具 -> 齿轮 -> 渐开线 中生成标准 DXF；
  • 来源二（外部 CAD 图档提取）：客户仅提供了一份从总装 CAD 图上截取的单齿槽 .dxf 文件，但该 DXF 的坐标原点在花键轴心 (0,0)(0,0)(0,0)（而非分度圆中径），且包含无法直接被老式磨床识别的 SPLINE 样条图元。

本案例以 60 齿精密渐开线花键 SPL-60T（模数 1.5 mm、齿数 60、压力角 30°、分度圆直径 90 mm） 为例，完整演示这两种路线及 DXF 处理 工具链的实战组合。

一、路线一：使用 绘图工具 -> 齿轮 -> 渐开线 一键生成花键 DXF

  1. 切换至 绘图工具 ➔ 齿轮 ➔ 渐开线；
  2. 填入 SPL-60T 花键设计参数：
    • 渐开线类型：下拉选择 花键（此时 齿高模式 自动隐藏，直接切换为直径输入模式）；
    • 法向模数：输入 1.5
    • 齿数：输入 60
    • 法向压力角：输入 30（右侧 右: / 左: 青绿微调框保持 0）
    • 螺旋角：输入 0（直齿花键填 0；若为螺旋花键则填入实际螺旋角并选择旋向）
    • 变位系数：输入 0；齿厚系数：输入 0.5（若需微调跨棒距 MMM 值，可在右侧 #6bb1aa 青绿框中填入微调量如 -0.012）
    • 齿高调节：填入 齿顶圆直径 = 91.5、齿根圆直径 = 88.2
    • 修整延长：输入 0.3
    • 齿顶倒圆半径：右: 输入 0.2，左: 输入 0.2
  3. 指定 保存文件 为 D:/IGD_Workspace/SPL-60T/SPL-60T_std.dxf，点击左下角 生成齿形文件。
    • 生成的 SPL-60T_std.dxf 已自动将分度圆直径 d=mnz=1.5×60=90 mmd = m_n z = 1.5 \times 60 = 90\text{ mm}d=mn​z=1.5×60=90 mm 对齐至 Y=0Y = 0Y=0 基准线，可直接送入 基本参数 生成砂轮修整宏程序！

二、路线二：外部非标 CAD 齿形 DXF 的坐标对齐、圆弧拟合与精度核验

假设客户直接发来一份从 CAD 总图上截取的原始文件 SPL-60T_raw.dxf，其圆心位于 (0,0)(0,0)(0,0)（即齿槽位于 Y≈+45 mmY \approx +45\text{ mm}Y≈+45 mm 处），且曲线为高阶样条 SPLINE。请按以下 3 步将其转化为合规的高精度修整数据：

步骤 1：用 DXF 变换 将分度圆基准平移至 Y=0Y = 0Y=0

  1. 切换至 工具箱 ➔ DXF 处理 ➔ DXF 变换；
  2. DXF 文件地址 选择 SPL-60T_raw.dxf；
  3. 保持 缩放比例 = 1.0、旋转角度 (顺时针+) = 0（若原始齿槽开口未朝向正上方 +Y+Y+Y，可先在此处输入旋转角度将其转正）；
  4. 在 平移距离 中：设置 X: = 0，Y: = -45（即将分度圆半径 R=90/2=45 mmR = 90 / 2 = 45\text{ mm}R=90/2=45 mm 向下平移至 Y=0Y = 0Y=0）；
  5. 点击左下角 生成变换 DXF，得到基准对齐后的 SPL-60T_aligned.dxf。

步骤 2：用 DXF 拟合圆弧 将样条转换为相切圆弧并校验残差

  1. 切换至 工具箱 ➔ DXF 处理 ➔ DXF 拟合圆弧；
  2. DXF 文件地址 选择 SPL-60T_aligned.dxf；
  3. 设置 拟合误差 = 0.5（单位：μm\mu\text{m}μm），曲线方向 选择 自动识别；
  4. 点击左下角 生成拟合数据：
    • 右侧画布下方子图实时显示圆弧拟合残差全程小于 ±0.5 μm\pm 0.5\ \mu\text{m}±0.5 μm，同时生成纯圆弧/直线图元的 SPL-60T_arc.dxf。

步骤 3：用 曲线误差对比 出具转换前后的微米级精度检验报告

  1. 切换至 工具箱 -> 曲线误差对比；
  2. 曲线 1 (基准) 选择步骤 1 对齐后的原始样条 SPL-60T_aligned.dxf；
  3. 曲线 2 (对比) 选择路线一生成的理论渐开线 SPL-60T_std.dxf（或步骤 2 的拟合圆弧 SPL-60T_arc.dxf）；
  4. 设置 最大误差距离 = 0.05、曲线方向 = X轴，指定保存路径后点击 生成误差对比数据；
  5. 点击右下角紫色的 误差曲线 按钮即可直观审阅全齿长偏差分布，最后将合格的 DXF 导入 基本参数（若仅需向车间线切割或光学磨床输出修整轮 CAD 图档，可在 高级参数 -> 程序信息 中将 程序模式 设为 模式-99），点击 生成代码 即可完成全部交付！
