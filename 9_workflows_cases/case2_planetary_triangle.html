9.2 多头行星滚柱丝杠

行星滚柱丝杠内齿圈常采用多头、90° 全角（45° 半角）精密内三角螺纹。本案例以脱敏标准算例 PRS-2065-3S 演示多头法向缩减配置与超小滚轮半径补偿。

工艺参数配置表（PRS-2065-3S）

参数面板 参数名称 设定值 说明
绘图工具 -> 三角 工件小径 / 工件中径 / 工件大径 19.32 mm / 20.0 mm / 20.72 mm 中径 20.0 mm 对齐 Y = 0 基准
工件螺距 / 工件头数 2.167 mm / 3 3 头螺纹，导程 2.167 × 3 = 6.501 mm
右半角 / 左半角 45.0° / 45.0° 行星丝杠 90° 全角标准牙型
齿顶倒圆半径 0.0 mm（或 0.08 mm） 按实际牙底过渡圆角设定
基本参数 工件类型 / 螺纹旋向 内螺纹 / 右旋 内齿圈磨削

砂轮杆偏移 范围 2.7 mm（或实际区间） 根据防撞校核结果设定

程序模式 模式-0 西门子 .SPF 宏程序

核心操作步骤

  1. 多头参数建模：在 绘图工具 -> 螺纹 -> 三角 分别填入单牙螺距 2.167 与头数 3（切勿直接填总导程），生成 PRS-2065-3S.dxf。
  2. 主参数载入与校核：在 基本参数 导入 DXF，取消角度自动同步后填入实际安装角 2.14°。
  3. 计算并复核视图：点击 生成代码 后在 干涉齿形 与 模拟计算 确认全齿高贴合无干涉。
