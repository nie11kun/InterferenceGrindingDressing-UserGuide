# 9.4 案例四：ZC1 圆弧圆柱蜗杆精密磨削与粗车刀设计（ZC1-9808）

圆环面包络圆弧圆柱蜗杆（**`ZC1`**）因其凸凹共轭接触线性能优异、易于形成动压油膜，广泛应用于重载电梯曳引机、精密回转工作台与工业机器人关节减速器。本案例以标准工业蜗杆 **`ZC1-9808`（外径 98 mm、轴向模数 2.3 mm、单头右旋）** 为例，演示如何在 IGD 中一次建模，同时打通**“路线 A：磨床精磨砂轮修整宏程序生成”**与**“路线 B：数控车床粗车成形刀刃口设计”**两条工艺路线！

---

## 一、第一步：在 `绘图工具 -> 蜗杆` 中建立 `ZC1-9808` 端面标准齿形

1. 切换至 **`绘图工具`** ➔ **`蜗杆`** ➔ **`圆弧圆柱(ZC)`** ➔ **`圆环面包络(ZC1)`**；
2. 依次填入 `ZC1-9808` 图纸参数：
   * **`输入模式`**：选择 `工件外径 (da)`
   * **`蜗杆外径`**：输入 `98`
   * **`轴向模数`**：输入 `2.3`
   * **`头数`**：输入 `1`
   * **`圆弧半径`**：输入 `9.5`（蜗杆齿侧母线圆弧半径 $\rho = 9.5\text{ mm}$）
   * **`标准砂轮直径`**：输入 `350`（定义包络生成该 ZC1 蜗杆理论螺旋面的基准砂轮直径 $D_{w0} = 350\text{ mm}$）
   * **`法向压力角`**：输入 `22.5`（右侧 `右:` / `左:` 青绿微调框保持 `0`）
   * **`变位系数`**：`0`；**`齿厚系数`**：`0.5`（右侧 `#6bb1aa` 青绿微调框可根据公法线或三针测量余量填入 `-0.0259`）
   * **`齿高模式`**：选择 `设置直径`，填入 **`齿顶圆直径`** = `98`、**`齿根圆直径`** = `86.96`
   * **`修整延长`**：输入 `0.5`
   * **`齿顶倒圆半径`**：`右:` 输入 `0.6`，`左:` 输入 `0.6`
3. 将 **`保存文件`** 路径设为 `D:/IGD_Workspace/ZC1-9808/ZC1-9808_end.dxf`，点击左下角 **`生成齿形文件`**。
   * 系统生成端面齿槽曲线 `ZC1-9808_end.dxf` 及伴随文件 `ZC1-9808_end-info.txt`（自动算出分度圆中径 $d = 93.4\text{ mm}$、导程 $P_h = \pi \times 2.3 \times 1 = 7.2257\text{ mm}$、标记 `DXF 齿形类型` = `端面(左)`）。

---

## 二、路线 A：生成精磨砂轮修整宏程序（当砂轮从 $\varnothing 400$ 磨损至 $\varnothing 300\text{ mm}$ 时）

> **工程痛点**：图纸规定 `ZC1-9808` 是由 $\varnothing 350\text{ mm}$ 标准砂轮包络定义的，但车间蜗杆磨床上的新砂轮直径为 $\varnothing 400\text{ mm}$，且一直要用到 $\varnothing 300\text{ mm}$ 才更换。如何保证无论砂轮是 $400\text{ mm}$ 还是 $300\text{ mm}$，磨出的蜗杆螺旋面始终与 $\varnothing 350\text{ mm}$ 标准砂轮包络出的螺旋面完全一致？

1. 切换至 **`基本参数`** 标签页，点击 **`DXF 齿型文件`** 右侧的 **`选择文件`**，加载刚才生成的 `ZC1-9808_end.dxf`；
   * 系统自动回填：**`工件类型`** = `外螺纹`、**`螺纹旋向`** = `右旋`、**`工件中径`** = `93.4`、**`导程`** = `7.2257`、**`DXF 齿形类型`** = `端面(左)`，并自动算出中径螺旋升角 **`1.4109°`**；
2. 在 **`基本参数`** 中设置实际磨床砂轮直径范围：
   * **`最大砂轮直径`**：`400`
   * **`最小砂轮直径`**：`300`
   * **`砂轮直径间隔`**：`5`（每隔 $5\text{ mm}$ 重新计算一档包络修正廓形，共 21 档）
   * **`砂轮安装角`**：保持勾选自动同步（`1.4109°`）；
3. 在 **`高级参数 -> 初始化配置`** 中设置：
   * **`滚轮圆弧半径`**：`右:` `0.5`，`左:` `0.5`
   * **`齿高延长高度`**：`0.2`，**`内收角度`**：`5`
   * **`齿根倒圆半径`**：`右:` `0.5`，`左:` `0.5`
   * **`拟合圆弧`**：`是`，**`拟合误差`**：`1`
4. 点击左下角 **`生成代码`**：
   * 在右下角 **`间隔变化`** 视图中可以看到：当砂轮直径为 $350\text{ mm}$ 时，修整出的砂轮齿侧正好是纯粹的 $R9.5\text{ mm}$ 圆弧；当砂轮为 $400\text{ mm}$ 或 $300\text{ mm}$ 时，软件自动对砂轮廓形进行了微米级曲率补偿，使磨出的蜗杆齿面恒定不变！

---

## 三、路线 B：通过 `曲线转换` + `车刀计算` 设计粗加工成形车刀

在蜗杆渗碳淬火前的数控车床开粗工序中，需要设计一把平前刀面、水平正装的成形车刀：

1. **先将 `端面(左)` 齿形转换为 `法向` 标准齿形**：
   * 切换至 **`工具箱 -> 曲线转换`**；
   * **`原始曲线类型`** 选择 `端面(左)`，**`目标曲线类型`** 选择 **`法向`**；
   * 导入 `ZC1-9808_end.dxf`（系统自动回填 `工件中径` = `93.4`、`导程` = `7.2257`）；
   * 保存路径设为 `D:/IGD_Workspace/ZC1-9808/ZC1-9808_normal.dxf`，点击左下角 **`生成曲线转换文件`**。
2. **若粗车需留单边 $0.15\text{ mm}$ 精磨余量（可选）**：
   * 进入 **`工具箱 -> DXF 处理 -> DXF 等距线`**，导入 `ZC1-9808_normal.dxf`，设置 **`等距宽度`** = `0.15`、**`等距方向`** = `曲线内侧`，点击 **`生成等距线`**，得到减薄了精磨余量的粗车目标法向槽形。
3. **在 `工具箱 -> 车刀计算` 中求解车刀刃口 DXF 与 3D 报告**：
   * 切换至 **`工具箱 -> 车刀计算`**；
   * 确认 `工件类型` = `外螺纹`、`螺纹旋向` = `右旋`、`工件中径` = `93.4`、`导程` = `7.2257`；
   * 输入车刀装夹角度：**`前角`** = `0`、**`侧倾角`** = `0`（水平装刀；若刀垫倾斜 $1.41^\circ$ 则填 `1.41`）、**`侧倾角偏移`** = `0`；
   * **`标准法向齿形文件`** 选择 `ZC1-9808_normal.dxf`，设置 **`车刀齿形保存路径`** 为 `D:/IGD_Workspace/ZC1-9808/ZC1-9808_lathe_tool.dxf`；
   * 点击左下角 **`生成车刀数据`**：直接获得线切割车刀片所需的 `ZC1-9808_lathe_tool.dxf` 与三维交互校验网页 `ZC1-9808_lathe_tool_3D.html`！
