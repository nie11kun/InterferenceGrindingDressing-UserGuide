# 9.4 ZC1 蜗杆与粗车刀

圆环面包络圆弧圆柱蜗杆（**`ZC1`**）兼具高精磨削与粗车开槽需求。本案例以脱敏标准代号 **`ZC1-9808`** 完整贯通**精磨砂轮修整宏程序**与**粗车成形车刀刃口反求**双路线。

---

## 双路线工艺流程

### 路线 A：精磨砂轮修整宏程序

1. 在 `绘图工具 -> 蜗杆 -> 圆弧圆柱(ZC) -> 圆环面包络(ZC1)` 填入参数并生成 **`ZC1-9808.dxf`**；
2. 切回 `基本参数` 载入该 DXF，系统经 `*-info.txt` 自动设置中径、导程与 `端面(左)`；
3. 输入工作砂轮直径上下限及间隔 `10.0 mm`，点击 **`生成代码`** 即自动补偿砂轮磨损引起的 ZC1 包络偏差。

### 路线 B：数控粗车成形车刀刃口设计

1. 打开 **`工具箱 -> 曲线转换`**，将 `ZC1-9808.dxf` 从 **`端面(左)`** 无损转为 **`法向`** 截形 `ZC1-9808_normal.dxf`；
2. 打开 **`工具箱 -> 车刀计算`**，导入 `ZC1-9808_normal.dxf`，设置车刀 `前角` 与 `侧倾角`（如 `34.7285°`）；
3. 点击 **`生成车刀数据`** 导出线切割用 `<文件名>.dxf` 及三维空间交线检验页 **`<文件名>-3D.html`**。
