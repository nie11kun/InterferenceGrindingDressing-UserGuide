9.1 案例一：内螺纹双圆弧滚珠丝杠螺母磨削修整（BNS-5250-2S）

二、主算例 BNS-5250-2S 端到端实操步骤

步骤 1：双头双圆弧齿形生成与垂直偏心微调

  1. 进入 绘图工具 -> 螺纹 -> 双圆弧，选择 计算系数 = 1.08，填入 钢球直径 = 9.525、接触角 = 45，点击 计算；
  2. 蓝灰色框（#78a6bc）自动生成理论值：右圆弧半径 = 5.1435、右水平偏心 = -0.2694、右垂直偏心 = -0.2694；
  3. 根据试磨工艺要求，将 右垂直偏心 与 左垂直偏心 右侧的 #6bb1aa 青绿色微调框 各填入 -0.0082；
  4. 填入 工件中径 = 52、工件大径 = 60.38、工件螺距 = 25、工件头数 = 2（注意：双头螺纹导程为 25×2=50 mm25 \times 2 = 50\text{ mm}25×2=50 mm）；
  5. 保存路径设为 D:/IGD_Workspace/BNS-5250-2S/BNS-5250-2S.dxf，点击 生成齿形文件。

步骤 2：在 工具箱 -> 最大偏移 中校核防撞安装角

  1. 切换至 工具箱 -> 最大偏移，输入螺母孔长 工件加工长度 = 115、螺母内孔 工件小径 = 49.5、砂轮杆直径 = 30；
  2. 测试发现若按理论螺旋升角 17.0° 倾斜，砂轮杆最大偏移裕度不足；将 砂轮杆安装角 调至 13.5° 时，理论最大偏移 达 5.82 mm，满足 ∅35 mm\varnothing 35\text{ mm}∅35 mm 最小砂轮切入深度要求。

步骤 3：配置 基本参数 与 高级参数 并生成西门子宏程序

  1. 切换至 高级参数 -> 初始化配置，将 输入方式 设为 砂轮直径，左右 滚轮圆弧半径 设为 0.25，左右 齿根倒圆半径 设为 0.25；
  2. 切换至 基本参数，加载 BNS-5250-2S.dxf（系统自动回填 工件中径 = 52、导程 = 50）；
  3. 填入 最大砂轮直径 = 43、最小砂轮直径 = 35、砂轮直径间隔 = 0.1；
  4. 关键一步：取消勾选 砂轮安装角 右侧同步复选框，手动填入步骤 2 校核确定的实际倾角 13.5；
  5. 点击左下角 生成代码。在右下角 干涉齿形 与 圆弧拟合 视图中可见：软件已精准补偿了 17.0054∘−13.5∘=3.5054∘17.0054^\circ - 13.5^\circ = 3.5054^\circ17.0054∘−13.5∘=3.5054∘ 安装角差引起的空间曲率干涉，拟合残差严格小于 1 μm1\ \mu\text{m}1 μm！
