9.1 双圆弧丝杠螺母

本案例以脱敏工业标准算例 BNS-5250-2S（双头重载内螺纹滚珠丝杠螺母） 为例，展示双圆弧建模、防撞偏移设定、侧边过切修正与西门子 .SPF 生成流程。

工艺参数配置表（BNS-5250-2S）

参数面板 参数名称 设定值 说明
绘图工具 -> 双圆弧 计算系数 / 钢球直径 / 接触角 1.06 / 7.938 mm / 45° 重载钢球公称规格
右圆弧半径 (#78a6bc + #6bb1aa) 4.2071 + 0 理论圆弧半径
左圆弧半径 (#78a6bc + #6bb1aa) 4.2071 + +0.02 左齿侧青绿框半径微调 +0.02 mm
水平偏心 (右: / 左:) 0.1684 / 0.1684 理论水平偏心
垂直偏心 (右: / 左: + #6bb1aa) 0.1684 / 0.1684 (+0.02) 左齿侧垂直偏心微调 +0.02 mm

拟合圆弧 / G3 ⇆ G2 / 拟合误差 是 / 勾选 / 1.0（0.1 μm） 单位 0.1 μm，生成 10 段平滑圆弧与 2 段直线
程序模式 模式-0 (DRESSER[24]) 输出 CV_51_80-50_00-3_50 全套文件

核心操作步骤

  1. 双圆弧建模与非对称微调：
    • 在 绘图工具 -> 螺纹 -> 双圆弧 填好 1.06、7.938、45 点击 计算；
    • 在左侧 #6bb1aa 框输入 +0.02 补偿，填入 51.8、54.0、25、2，生成 BNS-5250-2S.dxf。
  2. 主界面配置与代码生成：
    • 切回 基本参数 载入 DXF（自动回填中径与导程），设定偏移 13.2 ~ 16.0、安装角 3.5°；
    • 在 高级参数 开启 侧边修正 = 均衡过切和残留、确认 拟合误差 = 1.0（0.1 μm），点击 生成代码。
  3. 视图与输出复核：
    • 依次检视 圆弧拟合 与 模拟计算 视图，确认肩部孔口过切与残留均已均衡压低后拷贝 .SPF 上机。
