# 1.3 3 分钟快速上手：从齿形生成到 G 代码输出

本节通过一个工业级标准算例——**`BNS-2020-R` 内螺纹双圆弧滚珠丝杠螺母**，带您在 3 分钟内完成从**第 1 步建立标准双圆弧齿形 DXF**、**第 2 步配置基本与高级磨削参数**，到**第 3 步一键生成西门子数控修整宏程序（`.SPF`）并校验包络精度**的完整闭环。

---

## 算例工艺条件（型号：`BNS-2020-R`）

| 类别 | 参数名称 | 设定值 | 说明 |
| :--- | :--- | :--- | :--- |
| **工件与螺纹参数** | `工件类型` / `螺纹旋向` | `内螺纹` / `右旋` | 高导程内螺纹滚珠丝杠螺母 |
| | `工件中径` / `工件大径` | `20 mm` / `20.9 mm` | 螺母内孔滚道 |
| | `导程` (`工件螺距` $\times$ `工件头数`) | `20 mm` (`20` $\times$ `1`) | 大导程（螺旋升角高达 $17.6568^\circ$，空间干涉显著） |
| **双圆弧滚道参数** | `计算系数` / `钢球直径` / `接触角` | `1.08` / `3.175 mm` / `45°` | 标准哥特式（Gothic）双圆弧滚道 |
| **砂轮与修整参数** | `输入方式` | `砂轮杆偏移` | 最小偏移 `1.5 mm`，最大偏移 `3.0 mm` |
| | `砂轮直径间隔` / `砂轮安装角` | `0.1 mm` / `15°` | 每磨损 `0.1 mm` 切换一档修整参数 |
| | `滚轮圆弧半径` (`右:` / `左:`) | `0.2 mm` / `0.2 mm` | 金刚石滚轮左右圆弧刀尖半径 |
| | `拟合圆弧` / `拟合误差` | `是` / `1` ($\mu\text{m}$) | 输出 G2/G3 圆弧插补代码，允差 $1\ \mu\text{m}$ |
| | `程序模式` | `模式-0` | 西门子 `.SPF` 标准宏程序 |

## 第一步：在 `绘图工具` 中生成标准双圆弧齿形 DXF

1. 点击左侧顶部标签栏切换至 **`绘图工具`** ➔ **`螺纹`** ➔ **`双圆弧`**；
2. 依次填入双圆弧基础参数：
   * **`计算系数`**：选择 `1.08`
   * **`钢球直径`**：输入 `3.175`
   * **`接触角`**：输入 `45`
3. 点击面板中部的 **`计算`** 按钮：
   * 此时上方 6 个**蓝灰色输入框（`#78a6bc`）**会自动算出理论值：`右圆弧半径` = `1.7145`、`右水平偏心` = `-0.0898`、`右垂直偏心` = `-0.0898`（左圆弧对称）；
   * 若需消除大径处尖角并微调圆弧半径，可在 `右圆弧半径` 与 `左圆弧半径` 右侧的**青绿色微调框（`#6bb1aa`）**中输入 `-0.175`；
4. 在下方 **`直径信息`** 与 **`螺距信息`** 区域填入：
   * **`工件中径`**：`20`
   * **`工件大径`**：`20.9`（当在 `基本参数` 中将 `工件类型` 设为 `内螺纹` 时，此处标签自动显示为 `工件大径`）
   * **`工件螺距`**：`20`，**`工件头数`**：`1`
5. 点击 **`保存文件`** 右侧的 **`选择文件`**，将路径设为 `D:/IGD_Workspace/BNS-2020-R/profile.dxf`；
6. 点击左下角主按钮 **`生成齿形文件`**：
   * 右侧画布立即绘出绿色的双圆弧标准齿形曲线，底部提示 `左右圆弧X0处高度差: 0.0 mm`；
   * 系统同时在同目录下生成 `profile.dxf` 与记录了几何参数的伴随文本 `profile-info.txt`。

---

## 第二步：在 `基本参数` 与 `高级参数` 中配置磨削修整工况

1. 切换至左侧 **`基本参数`** 标签页：
   * **`工件类型`**：选择 `内螺纹`；**`螺纹旋向`**：选择 `右旋`；
   * 点击 **`DXF 齿型文件`** 右侧的 **`选择文件`**，选中刚才生成的 `profile.dxf`；
   * **自动回填机制触发**：由于同目录存在 `profile-info.txt`，软件会自动读取其中的 `工件中径` (`20`) 与 `导程` (`20`) 填入对应输入框，并在 `砂轮安装角` 右侧自动算出理论螺旋升角 **`17.6568°`**！
   * **`DXF 齿形类型`**：保持默认 `法向`（由 `绘图工具 -> 螺纹` 生成的齿形均为法向截面）；
   * **`砂轮杆偏移工件中心最小距离`**：输入 `1.5`；
   * **`砂轮杆偏移工件中心最大距离`**：输入 `3.0`；
   * **`砂轮直径间隔`**：输入 `0.1`；
   * **`砂轮安装角`**：由于内螺纹孔径限制，取消勾选右侧自动同步复选框，手动输入实际砂轮杆倾角 `15`。
2. 切换至左侧 **`高级参数`** ➔ **`初始化配置`** 子标签页：
   * **`滚轮圆弧半径`**：`右:` 输入 `0.2`，`左:` 输入 `0.2`；
   * **`最终曲线点密度`**：保持 `600`；**`螺旋面生成角度`**：保持 `90`；
   * **`齿高延长高度`**：输入 `0.1`，**`内收角度`**：输入 `5`；
   * **`齿根倒圆半径`**：`右:` 输入 `0.2`，`左:` 输入 `0.2`；
   * **`水平延长`**：选择 `否`；
   * **`拟合圆弧`**：选择 `是`（不勾选 `G3 ⇆ G2`），**`拟合误差`**：保持 `1`；
   * **`输出程序路径`**：点击 **`选择路径`**，指定输出文件夹 `D:/IGD_Workspace/BNS-2020-R/output`。
3. 切换至 **`高级参数`** ➔ **`程序信息`** 子标签页：
   * **`程序头加载齿形信息`**：选择 `是`（将参数写入 G 代码头部注释，便于现场核对）；
   * **`程序模式`**：选择 `模式-0`（西门子标准 `.SPF` 模板），**`修整轴名称`** 保持 `水平:` `W`、`进刀:` `U`，**`进刀方向`** 选择 `负向`。

---

## 第三步：点击 `生成代码` 并审阅 6 大计算结果视图

1. 点击左下角主按钮 **`生成代码`**；
2. 经过约 2~5 秒的空间螺旋面啮合包络求解与双圆弧拟合，弹出成功提示后，依次点击右下角 6 个视图按钮检查计算质量：
   * **`加载图形`**：确认导入的 `profile.dxf` 原始双圆弧齿形无断点、方向朝向正确；
   * **`间隔变化`**：查看从最小砂轮直径到最大砂轮直径每隔 `0.1 mm` 变化的廓形族（内侧红线代表最大偏移/最小砂轮，外侧灰线代表最小偏移/最大砂轮）；
   * **`圆弧拟合`**：上方子图显示多段 G2/G3 圆弧切点分布，下方子图显示实际拟合残差——确认所有残差峰值均严格控制在 `±1 μm` 红虚线包络带内；
   * **`干涉齿形`**：检视去除干涉后的实际砂轮截形（蓝色实线）与理论目标齿形之间的空间包络修正量；
   * **`修形轮廓`**：查看叠加了左右 `0.2 mm` 金刚石滚轮半径偏置后的 CNC 修整刀位轨迹（左修整红线 + 右修整蓝线）；
   * **`模拟计算`**：检查最终生成的 G 代码段在每个直径阶梯下的左右修整走刀路径。
3. 打开输出目录 `D:/IGD_Workspace/BNS-2020-R/output`，即可获取可直接拷入西门子 840D sl / ONE 系统的修整宏程序 `.SPF` 文件及配套 `.dxf` 廓形图。
